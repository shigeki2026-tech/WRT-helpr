## 7. WRS引き継ぎと修理拠点判定の関係

確認日：
2026/06/25

### 7-1. コード上の前提

app.py の determine_wrs_handover_action は、修理拠点判定とは別軸で動く。

重要な仕様：

- WRS引き継ぎ判定は master_wrs_handover_rules.csv を参照する
- 修理拠点判定は master_vendor_rules.csv を参照する
- WRS引き継ぎ判定は vendor_name を変更しない
- WRS引き継ぎ判定は修理依頼先を上書きしない
- WRS引き継ぎは終話後の受付報告・転記用表示として扱う

つまり、以下は併存する設計である。

- 修理拠点：ユナイトサービス㈱
- WRS引き継ぎ：あり
- WRS依頼先：【BKK】WRS（福岡）へ対応依頼

### 7-2. テストで固定済みの代表例

既存テストで以下が固定されている。

#### アイ工務店

- vendor はユナイトサービス㈱のまま
- vendor_result.reason は No.7 fallback
- WRS引き継ぎはアイ工務店として必要
- WRSは vendor を上書きしない

#### 京阪

- WRS引き継ぎ対象
- rule_name は京阪
- WRS転記用に ALSOK入力有無の注意が残る

#### コーナン住設

- コーナン / ビーバートザンは、住設案件のみWRS引き継ぎ対象
- 家電案件ではWRS引き継ぎ対象にしない

#### 通常案件

- 通常販売店では WRS引き継ぎなし
- 出張修理は No.7 fallback によりユナイトサービス㈱へ流れる

### 7-3. 水栓系マスタ整備への影響

水栓系を出張修理として登録した場合、修理拠点は通常どおり vendor 判定で決まる。

一方、京阪・コーナン住設などのWRS対象案件では、修理拠点とは別に WRS引き継ぎ表示が出る。

したがって、水栓系マスタ整備では以下を分けて判断する。

1. 水栓系の修理形態
2. 水栓系の概算費用
3. 水栓系の修理拠点
4. 京阪・コーナン住設などのWRS受付報告要否

WRS引き継ぎ対象だからといって、修理拠点をWRSへ変更しない。
修理拠点がユナイトだからといって、WRS受付報告を消さない。

### 7-4. 現時点の判断

WRS引き継ぎと修理拠点の併存設計は、既存コード・既存テストで固定済み。

したがって、水栓系マスタ整備で追加確認すべき主論点は以下に絞る。

- 水栓系を出張修理にするか
- 費用は汎用 5,000円～7,000円でよいか
- 国内メーカー表記をどう扱うか
- 京阪・コーナン住設の水栓案件で、WRS受付報告に追加文言が必要か
