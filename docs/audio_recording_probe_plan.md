# 音声プローブ 非干渉検証計画

## 目的

WRT-helpr 本体へ録音機能を戻す前に、現在の通話音声経路、使用デバイス、禁止事項、撤退条件を明文化する。これは録音機能の実装ではない。

この検証は WRT 本体と完全に分離する。`app.py`、Streamlit ページ、Teams 送信、ラクテル文生成、通話開始エリアからプローブを呼び出さない。録音開始ボタン、録音停止ボタン、録音保存、文字起こし UI は作らない。

## 絶対禁止事項

- 本番通話中に検証しない。
- Windows の既定入力デバイス、既定出力デバイス、既定通信デバイスを変更しない。
- 音声デバイス設定、Voicemeeter、VB-CABLE、Jabra、Windows 音声設定を変更しない。
- プローブスクリプトから音声デバイスを開かない。
- プローブスクリプトで録音しない。
- 録音ファイルを保存しない。
- 文字起こしを実行しない。
- `sounddevice`、`soundfile`、`faster-whisper`、`numpy` を追加しない。
- `audio_devices.py`、`transcribe.py`、`pages/09_通話録音.py` を復活させない。
- 旧録音 commit を戻さない。
- Teams 送信本体、Graph 認証、`chat_id` 設定を変更しない。

## 検証してよい条件

- 本番通話が完全に終了している。
- 着信待機や折り返し予定がない時間帯である。
- 異常が出たらすぐ WRT と検証スクリプトを閉じられる。
- 検証前の Windows 音声設定、Voicemeeter、VB-CABLE、Jabra の状態を目視で確認済みである。
- 検証は音声デバイス一覧の表示までに限定する。

録音テストをしてよい時間帯は、業務通話が止まっている時間帯だけとする。本番通話中、通話待機中、折り返し直前、Teams 会議中は検証禁止。

## 独立プローブスクリプト

`scripts/audio_device_probe.py` は WRT 本体から呼び出さない独立スクリプトである。

このスクリプトが行うこと:

- 標準ライブラリだけを使う。
- Windows では PowerShell の読み取り専用コマンドで音声関連デバイス名を列挙する。
- 取得できない場合は、手動確認手順を表示する。
- デバイス名、状態、取得元を標準出力へ表示する。

このスクリプトが行わないこと:

- 音声デバイスを開かない。
- 録音しない。
- 既定デバイスを変更しない。
- OS 設定を変更しない。
- Voicemeeter、VB-CABLE、Jabra 設定を変更しない。
- WRT 本体へ結果を書き戻さない。

実行例:

```powershell
python .\scripts\audio_device_probe.py
```

## 取得できない場合の手動確認

スクリプトで一覧を取得できない場合は、以下を手動で確認し、この文書の記録欄へ転記する。

1. Windows の「設定」から「システム」→「サウンド」を開く。
2. 入力デバイス、出力デバイス、通信デバイスの表示名を確認する。
3. Jabra Direct、Voicemeeter、VB-CABLE を使用している場合は、現在選択中のデバイス名だけを確認する。
4. 設定は変更しない。クリックで選択状態が変わりそうな画面では確認だけに留める。

## 異常時の即時撤退条件

以下のいずれかが起きた場合、検証を停止し、WRT 本体への録音組み込みを進めない。

- 通話音声が聞こえない。
- 相手に声が届かない。
- 音量、入力先、出力先、通信デバイスが変わる。
- Windows の既定デバイスや通信デバイスが変わる。
- Voicemeeter、VB-CABLE、Jabra 側のルーティングや選択状態が変わる。
- Teams、ブラウザ通話、既存の電話環境に影響が出る。
- 復旧に OS 設定変更、デバイス再選択、再起動が必要になる。

撤退後は、変更前の状態に戻せる担当者だけが手動で復旧し、原因が特定できるまで録音検証を進めない。

## WRT 本体へ組み込んでよい条件

- 本番通話外で、音声デバイス一覧確認が通話経路へ影響しないことを複数回確認済みである。
- 検証前後で Windows 既定デバイス、通信デバイス、Voicemeeter、VB-CABLE、Jabra 設定が変わっていない。
- 読み取り専用の確認手順と撤退手順が運用者に共有されている。
- 録音実装に進む場合も、WRT 本体への組み込み前に別タスクで設計とテスト方針を合意する。

## WRT 本体へ組み込んではいけない条件

- 本番通話中に検証しただけである。
- 一度でも通話音声が無音、片方向、入力先変更、出力先変更になった。
- デバイス一覧取得だけで OS や通話アプリに影響が出た。
- `sounddevice` など録音ライブラリの導入可否が未判断である。
- 録音ファイル保存、文字起こし、Streamlit UI を同時に入れようとしている。
- Teams 送信やラクテル文生成など、録音以外の本体機能と同時変更になる。
